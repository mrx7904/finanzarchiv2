# Conventions

> Read before implementing or modifying code or documents.

## Language

| Artefact | Language |
|---|---|
| `CLAUDE.md`, `knowledge/`, code, comments, identifiers, test names, commits, branches, PR titles | English |
| `spec/concept.md`, `spec/requirements.md`, `issues/` | English |
| `README.md`, `docs/` and every other documentation for people | German |
| User-facing strings | German only |

German domain terms stay German as identifiers where English would blur them (`Gehaltsabrechnung`, `Brutto`, `Netto`, `Lohnsteuer`, `Kontoauszug`). Vault-wide rule: `~/Entwicklung/AgentOS/knowledge/project-language-split.md`. Texts follow the owner's style from `essentials.md`, section 3: no semicolons, no dashes as punctuation, a colon only before a list or a quotation.

## User-facing language

**Decided:** 2026-11-25, carried over from version 1.0

The app has one user, the owner, and the documents are German. Strings are written in German directly in the components. There is no i18n layer. Do not introduce one without a decision recorded here.

## Public repository

**Decided:** 2026-11-25 by the owner. The repository `mrx7904/finanzarchiv2` is public. What may enter it stands in [`decision-public-repository.md`](decision-public-repository.md). In short: no real document, amount, name, IBAN, mail address or local path, test data are generated, and the check refuses what looks like personal data.

## Code

- Comments explain why, never what.
- One source of truth per value. A default lives in one place in the core and nowhere else.
- No secrets in the repository. Mail credentials live in the system's credential store (`keyring`). Local paths and overrides live in `.env` (ignored), `.env.example` names every key without a value.
- The archive stays on the machine, data may be fetched. No content of the archive, no document, text, amount or name, goes to a third-party service. Every network call goes to a host in the table "Outside connections" below, a call to another host is a fault. This rule is taken over from 1.0 (`decision-outside-connections.md` there, 2026-11-14).
- Amounts are integer cents: the newtype `Cents(i64)` in Rust, `number` of whole cents in TypeScript, `INTEGER` in SQLite. Never a float.
- Architecture decisions go to `knowledge/decision-*.md` before or with the change.

### Outside connections

| Host | Purpose | What it receives | Since |
|---|---|---|---|
| `OLLAMA_HOST`, default `127.0.0.1:11434` | the local model reads documents | the text and page images of documents, so it runs on a machine of the owner, never a hosted service | planned for stage 2 |

### Rust (core, `src-tauri/`)

- Edition 2024, stable toolchain pinned in `rust-toolchain.toml`.
- `cargo fmt` formats, `cargo clippy --all-targets -- -D warnings` lints. `unwrap` and `expect` are denied outside tests (`clippy::unwrap_used`, `clippy::expect_used`).
- Errors are typed with `thiserror` per module. A command returns `Result<T, AppError>`, and the UI receives a German message and a kind, never a message of a library that could quote a document.
- Domain logic lives in plain modules without Tauri types, so it is tested without a window. Tauri commands are thin.
- The database is reached only through the repository modules, queries use parameters, never string concatenation.
- Logs name what failed and the kind of the error, never a value of the archive (rule of 1.0, `decision-resilience.md` there).

### TypeScript (UI, `src/`)

- Strict, including `noUncheckedIndexedAccess`. No `any`, `import type` for types.
- The UI calls the core only through the bindings generated by `tauri-specta` (`src/bindings.ts`). Nobody edits the generated file. After a change to a command or one of its types, `npm run bindings` regenerates it, and the check fails until it is current.
- The UI holds no business rule. Sums, matching and checks come from the core.

### Tauri

- Every window has a capability file that allows only what it uses. A new permission is named in the change that needs it.
- The window loads only the app's own pages. A CSP is set in `tauri.conf.json`, nothing is loaded at run time from the network.

### Database

- Schema changes are numbered SQL files, embedded into the binary, applied in order and never edited after they were committed.
- Tables are `STRICT` with foreign keys on.

## Formatting and linting

`cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `npm run typecheck` and `npm run lint` (oxlint). All of them run in the check below. There is no CI, see [`decision-local-builds.md`](decision-local-builds.md).

## Check

The command an AgentOS session must pass before it may end. The backend reads this line.

Check: `node scripts/check.mjs`

It checks the links of the Markdown files, the traceability between requirements and issues and that no personal data stands in a tracked file, then runs `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test` in `src-tauri/` and `npm run typecheck`, `npm run lint` and `npm test`. `node scripts/check.mjs --self-test` proves that each step passes on the clean tree and fails on a planted fault, and gives the tree back as it was. A new step gets its probe in `CODE_STEPS` in the same change.

Prerequisites of a machine: Node 24 or newer, Rust through rustup (the toolchain of `rust-toolchain.toml` installs itself), on Windows the workload "Desktop development with C++" of Visual Studio, on macOS the Xcode command line tools (`decision-stack.md`, "The shell of #01").

`npm run tauri dev` starts the app with the dev server, `npm run tauri build` builds it.

## Machine settings

The vault plugin needs the path of the vault, which differs per machine and must not enter the public repository. Each machine keeps it in `.claude/settings.local.json` (ignored):

```json
{ "extraKnownMarketplaces": { "agentos-vault": { "source": { "source": "directory", "path": "<path of the vault>" } } } }
```

## Specification
