# Decision: a public repository without a licence and without personal data

**Decided:** 2026-11-25 by the owner (public repository, no licence) · applies to every tracked file and every commit

## Decision

- `mrx7904/finanzarchiv2` is public. It carries no licence file, so all rights stay with the owner, the code may be read but not reused.
- No real document, amount, name, IBAN, mail address, address, tax number or local path enters a tracked file, a test or a commit message. Version 1.0 was private and its tests and decision files quote values of the owner's archive. Nothing is copied from there without reading it first.
- Test documents are generated by code (#09) with invented senders, numbers and IBANs, and lie under `fixtures/synthetic/`.
- Real documents for measuring stay outside the repository, in a folder named by `.env` (`CORPUS_PRIVATE`), and their results go to an ignored folder. A published measurement gives counts only.
- The machine paths of Claude Code (the vault plugin) stand in `.claude/settings.local.json`, which is ignored.
- Commits are authored as `mrx7904 <mrx7904@users.noreply.github.com>`, set in the local git config, not with the mail address of the machine.
- From Aceternity UI and 21st.dev only the idea is taken, never source. Their licences forbid redistributing the code, and a public repository is a redistribution (`decision-ui-libraries.md`).

## Enforcement

`node scripts/check.mjs` scans every tracked file and refuses an IBAN with a valid check sum outside `fixtures/synthetic/` (since 2026-11-25 a string with a wrong check sum is no account and is not refused, and the two public examples of ISO 13616, DE89 3704 … and GB82 WEST …, are allowed for tests), a mail address other than an example or noreply address, and an absolute path into a user's home folder. `--self-test` proves the scan fails on each.

## Why

The owner allowed the repository to be public and asked that this is respected (2026-11-25). An archive of one's own finances is the most private data an app can hold, and a public history can never be cleaned completely.

## Test data are invented

**Decided:** 2026-11-25, after a near miss: a probe IBAN for the self-test was built from the digits of the owner's real account, read from a file name in a screenshot. It was caught before any commit and replaced. Test values are invented from scratch (bank code `12345678`, account `0000004711`) or are public examples of a standard, never taken from anything the owner showed or the archive holds. The self-test builds its probe IBAN at run time, so no file holds one.
